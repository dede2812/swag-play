# 02 · Investigación de videojuegos publicitarios (advergames)

> Fase 2 del Prompt Maestro — qué hace que un juego de marca funcione en 2024-2025.

## Hallazgos clave

1. **"Snackable" y honesto gana.** Los advergames efectivos priorizan experiencias cortas que integran los valores de marca de forma natural, no logos agresivos. El gameplay "honesto" (el anuncio jugable = el juego real) mejora la retención a largo plazo.
2. **Velocidad de carga crítica:** < 1.2 segundos. Cada segundo de espera mata la curiosidad del público joven.
3. **Mecánicas por posicionamiento:** endless runners para marcas de energía/movimiento; puzzles para inteligencia; quizzes para datos. SWAG = energía + organización → **runner con decisiones de equilibrio**.
4. **Viralidad = mecánicas sociales:** retos competitivos, clips/tarjetas compartibles, leaderboards. Para público menor: tarjeta de resultado compartible (cliente, sin servidor) en vez de leaderboard público.
5. **Retención sin dark patterns (Duolingo, Nike Run Club):**
   - Rachas y progreso visible (deseo de completar).
   - Hitos y medallas que celebran logros concretos (Bronce/Plata/Oro, "Semana superada").
   - Feedback positivo alto ("¡fantástico!", celebraciones) alarga sesiones.
   - Ligas/semanas reiniciadas mantienen la competencia alcanzable — traducido a "¿puedes con la semana?".
   - Retos entre amigos > compras.
6. **Recompensas claras:** insignias y desbloqueos cosméticos funcionan sin costo ni presión económica — ideal para menores.

## Referentes analizados

| Referente | Qué toma SWAG RUSH |
|---|---|
| Endless runners (Subway Surfers, Temple Run) | 3 carriles, gestos swipe, salto, dificultad creciente, "una partida más" |
| Duolingo | Rachas/progreso, feedback positivo, medallas por hitos |
| Nike Run Club | Retos personales y distancia como métrica orgullosa de compartir |
| Playable ads honestos | El juego anuncia exactamente lo que la marca hace (equilibrar tu semana) |
| Tarjetas de resultado (Wordle-style) | Imagen generada en el cliente, lista para historia/post |

## Requisitos derivados para el diseño

- [x] Jugar en < 5 s desde abrir la página (menú → cuenta atrás).
- [x] Diversión en los primeros 10 s (ítems, partículas, sonido inmediatos).
- [x] Mecánica que ES el mensaje: equilibrar Academia + Deporte + Bienestar = MODO SWAG.
- [x] Sesión corta (~2 min la semana completa) con rejugabilidad (medallas, estilos, récord).
- [x] Compartir sin servidor ni datos personales (tarjeta PNG local + Web Share API).
- [x] CTA no intrusivo al final, nunca mid-game.
